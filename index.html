Shortcuts

      

        
Click / Shift-clickSelect shape / add to selection

        
Drag handleEdit; ghost (hollow) handles insert a point or convert S→C, T→Q

        
Shift-click / marqueeSelect several points; drag one to move all

        
Arrows (Shift)Nudge 1 (10) screen px

        
⌫ / DeleteDelete selected points, else shapes

        
Double-click anchorCycle corner → smooth → symmetric

        
Double-click groupEnter group (Esc leaves)

        
ShiftAspect ratio / 15° angle snap / keep rx:ry

        
AltResize from centre / rx = ry / break smooth node

        
Ctrl (while dragging)Bypass snapping

        
Space-drag / wheelPan; ⌘/Ctrl-wheel or pinch zooms

        
Right-clickArc flags, node type, convert, delete
